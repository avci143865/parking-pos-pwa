# ادارة الكراج — تطبيق POS (PWA)

تطبيق كراج يعمل كتطبيق ويب قابل للتثبيت على أجهزة أندرويد POS: مسح QR بالكاميرا أو بقارئ الجهاز، وطباعة إيصالات حرارية.

## على جهاز POS (أندرويد)

1. افتح الرابط بـ **Brave** أو Chrome (HTTPS مطلوب للكاميرا؛ على نفس الجهاز يكفي `http://127.0.0.1` أحيانًا).
2. من القائمة: **تثبيت التطبيق** / Add to Home screen حتى يعمل بملء الشاشة بدون شريط المتصفح.
3. اسمح بالكاميرا عند أول مسح.
4. في مكتب الإدخال:
   - فعّل **قارئ POS** إذا كان الجهاز يرسل الباركود كلوحة مفاتيح.
   - اختر عرض الورق **80 ملم** أو **58 ملم**.
   - **ربط طابعة بلوتوث** للطابعات الحرارية العامة، أو استخدم طابعة Sunmi الداخلية إن وُجدت.
   - فعّل **طباعة الإيصال تلقائيًا** بعد الدخول.

الطباعة بالترتيب: طابعة الجهاز الأصلية → بلوتوث ESC/POS (صورة الإيصال بالعربية) → نافذة طباعة أندرويد.

## تشغيل محلي (ويندوز)

```powershell
.\run.ps1
```

ثم افتح `http://127.0.0.1:8000` في Brave.
